Python Text Encryption & Decryption Tool

A simple, lightweight text encryption tool built in Python. It uses a **randomly generated substitution cipher** to scramble and unscramble text — perfect for learning the basics of encryption and cryptography.

 Project Overview

This tool demonstrates a classic **substitution cipher**: every character in your message is replaced by a different character from a randomly shuffled character set.

It's built as part of a cybersecurity learning journey to understand how encryption works at its most fundamental level — no libraries, no algorithms, just pure Python logic.

Features

- **Simple & Educational** – No external dependencies; pure Python.
- **Encryption** – Scrambles your message into unreadable ciphertext.
- **Decryption** – Restores the original message from the ciphertext.
- **Random Key Generation** – A new substitution key is generated each time the program runs.

Requirements

- Python 3.6 or higher
- No external packages required
